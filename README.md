**Flask** is a **lightweight WSGI web application framework**
- why Flask is lightweight?
- what is WSGI?

Flask depends on:
- **Werkzeug** WSGI toolkit, standard Python interface between applications and servers ?
- **Jinja** template engine that renders the pages the application serve
- **MarkupSage** escapes unstructed input when rendering template to avoid injection attacks ?
- **ItsDangerous** securly sign data to insure its integrity, protects Flask session cookies ?
- **Click** CLI toolkit, it provides the **flask** command and allows adding custom management commands
- **Blinker** provide support for **Signals** ?
